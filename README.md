# 良值复古迷你手柄 2（IINE Mini Retro Ananke Gen 2）· Windows 改键工具

在 PC 上改手柄键位：本地起一个桥，浏览器里点按键就能改，不用装手机 App。

> **本仓库的代码、文档与协议结论完全由 AI 生成**，未经人工逐行审阅；使用前请自行核对，按需修改。

- 手柄：良值（IINE）复古迷你手柄 2 · `VID 1000 / PID 2001` · `joymi` 平台
- 通道：BLE 服务 `0xAE40`（写 `0xAE41`，通知 `0xAE42`），msgpack 报文

## 运行

需要 Windows 10 及以上、Python 3.10+。

```bash
pip install -r requirements.txt
python analysis/bridge.py --port 8848 --open
```

浏览器会自动打开 `http://127.0.0.1:8848/keymap.html`，点「连接手柄」。

参数：`--addr <MAC>` 指定地址 · `--no-auto` 启动时不自动连 · `--chunk N` 改分片大小 · `--no-open` 不自动开浏览器

## 手柄档位（最影响成败）

手柄拨到不同档位，连 Windows 的方式完全不同：

| 档位 | Windows 侧连接方式 | 实测结果 |
|---|---|---|
| **鼠标档** | BLE HID（`BTHLE`，链路现成） | **最推荐**，1.5 秒连上 |
| **键盘档** | 经典蓝牙 HID | 首连约 8 秒，重连约 1 秒 |
| 私有 / 配置档 | 不连（无驱动） | 专为配置设计，稳定 |
| Xbox 档 | 经典蓝牙 HID | 重启后要等链路稳定，可能 2~3 分钟 |
| Switch 档 | 经典蓝牙（`Pro Controller`） | 最难，只能抢经典连接断开的瞬间 |

改键用鼠标档或私有档，改完拨回去打游戏，配置存在固件里不会丢。

手柄每切一次档，BLE 地址都会变（随机地址），程序按「扫描 → 上次连成功的地址 → 已配对列表」逐级找回：先扫到广播就用扫描结果（地址一定是新鲜的），扫不到才用上次的地址（鼠标档连上 Windows 后不广播，这是主要场景），最后才是配对表。

## 界面

五栏：**手柄**、**键盘**、**鼠标**、**媒体键**、**其他**。

手柄 / 鼠标 / 媒体键三栏顶部都有三个一键布局按钮：`横着拿`、`竖着拿 · 键在上`、`竖着拿 · 键在下`。点一下就把十字键的四个方向一次排好，不用一个键一个键改。

点改键面板左侧的「原始键位」框可以把这个键**还原成出厂键位**（键盘回出厂键码、媒体回出厂 Consumer usage、鼠标回无动作，只改草稿，需按「应用」）。改完点「应用」写入固件，程序自动回读校验。

### 手柄栏

17 个实体键互相映射，带「改键方式」开关：`单向赋值`（只改这一个键）/ `交换两键`（两个键互调）。

```
A  B  X  Y  L  R  ZL  ZR  −  +  HOME  截图  ▲  ▼  ◀  ▶  M1
```

### 鼠标栏

| 操作 | 写入值 |
|---|---|
| 左键 / 右键 / 中键 / 后退 / 前进 | `but` = 1 / 2 / 4 / 8 / 16，可相加（3 = 左右一起按） |
| 滚轮上 / 滚轮下 | `w` = ∓步数，步数可调 **1–20** |
| 上移 / 下移 / 左移 / 右移 | `x` / `y` = ±步长，步长可调 **1–48** |

### 媒体键栏

5 组共 37 项，写入的是 **HID Consumer Page（0x0C）标准 usage**，不是 App 的私有编号。

| 分组 | 可选项 |
|---|---|
| 播放控制 | 播放/暂停 `0xCD`、播放 `0xB0`、暂停 `0xB1`、停止 `0xB7`、上一首 `0xB6`、下一首 `0xB5`、快退 `0xB4`、快进 `0xB3`、录音 `0xB2`、弹出 `0xB8` |
| 音量与亮度 | 音量+ `0xE9`、音量- `0xEA`、静音 `0xE2`、亮度+ `0x6F`、亮度- `0x70`、频道+ `0x9C`、频道- `0x9D` |
| 方向 / 确认 | ▲ `0x42`、▼ `0x43`、◀ `0x44`、▶ `0x45`、确认 `0x41`、退出/Esc `0x46` |
| 系统 | 电源 `0x30`、睡眠 `0x32`、菜单 `0x40`、计算器 `0x192`、我的电脑 `0x194`、邮件 `0x18A` |
| 浏览器 / 遥控器 | 主页 `0x223`、返回 `0x224`、前进 `0x225`、刷新 `0x227`、搜索 `0x221`、收藏 `0x22A`、停止 `0x226`、浏览器 `0x196` |

`cs` 是 16 位字段，固件原样转发，所以列表之外的 usage 也能写——查 HID Usage Tables 的 Consumer Page 一节即可。

### 其他栏

无操作自动关机时间，`−` / 输入框 / `＋` 三件套，范围 **0–240 分钟**，0 = 永不关机（出厂已连接 3 分钟、未连接 5 分钟，后者固件写死改不动，界面不再显示）。

## 协议要点

帧格式：`B4 | LEN | SEQ | CC | payload`。`LEN` 为整帧长度；`SEQ` 高位 `0x80` 表示消息首帧、低位 `0x7F` 为 1 表示末帧；分片净载荷 = `MTU - 7`（协商到 64，即每片 57 字节）。

| 表 | 命令 | 结构 |
|---|---|---|
| 键盘 | `get_kb` / `set_kb` | `{key: u8, fn: u8, kb: [键1, 键2, 槽位号]}` |
| 手柄 | `get_gp` / `set_gp` | `{key: u8, gp: u8}`，`gp` 是目标槽位 |
| 鼠标 | `get_mouse` / `set_mouse` | `{key: u8, but: u8, w: i16, x: i16, y: i16}` |

字段位宽有几个坑：`but` 实际只有 **5 位**（写 33 回读 1、写 255 回读 31，32 以上直接丢）；`w` / `x` / `y` 协议写 int16，固件按 **int8** 存，超出 ±127 会回绕（写 300 回读 44）。所以滚轮步数与移动步长都在 int8 范围内取。
| 媒体键 | `get_cs` / `set_cs` | `{key: u16, cs: u16}`，Consumer Page usage |
| 关机 | `get_sleep` / `set_sleep` | `{discon: u8, con: u8}`，分钟，0 = 不关 |

写表一律**全量**：条目数要与读到的条数一致，只发一条固件会忽略。`set_*` 没有 ACK，是否写入成功只能靠回读判断。

槽位号：`0=A 1=B 3=X 4=Y 6=L 7=R 8=ZL 9=ZR 10=− 11=+ 12=HOME 15=截图 16=↑ 17=↓ 18=← 19=→ 23=M1`

槽位 12 / 15 对应底边两个圆键：**左圆 = 截图、右圆 = HOME（按实物印刷）**，槽位 12 是 HOME、15 是截图。这几个是实测出来的，官方 App 主页面把两个图标画反了，别照着抄。
